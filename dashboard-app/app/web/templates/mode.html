Cambiar modo de operación
Enviá un comando a la base para cambiar el comportamiento de un nodo (CONT / LP).
Enviar configuración
Completá los campos y presioná Enviar.
Nodo destino
Seleccioná el nodo al que querés aplicar el cambio. Nota: con el firmware actual de la base, el CFG se envía al nodo 1 (el selector queda listo para cuando agreguemos addressing).
Modo
CONT: el nodo envía periódicamente (modo demo). LP: el nodo duerme y despierta por intervalos.
intervalo (LP)
Tiempo entre mediciones y envíos en minutos. (Por detrás se convierte a segundos para el comando LP). Ej: 15 = 15 min.
prewarm_s (LP)
Tiempo (s) que el GPS se enciende antes de intentar un fix. Ayuda a estabilizar.
extra_s (LP)
Tiempo (s) adicional para buscar fix / completar medición antes de volver a dormir.
(*) ¿Cuándo se aplica el cambio?
La PC envía el comando a la Base por USB. La base guarda la configuración como “pendiente” y la transmite al nodo apenas recibe el próximo DATA de ese nodo (para aprovechar la ventana RX). Si el nodo no lo recibe en esa ventana, se reintenta en el próximo ciclo.
